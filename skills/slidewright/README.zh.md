# SlideWright

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

构建适合投影的网页幻灯片，让演讲者主导整个现场。

## 快速安装

```bash
npx skills add tronghieu/agent-skills --skill slidewright
```

## 立即尝试

```text
/slidewright 为产品负责人制作一套关于实用 AI Agent 的 10 分钟会议演示。采用温暖的编辑式视觉方向，并附带讲者备注。

/slidewright 把这些项目路演笔记变成一套面向投资人的 12 页演示文稿。场地使用 16:9 屏幕；使用我们的标志，并让叙事果断但不夸张。

/slidewright 重新设计我现有的工作坊演示文稿以供投影：每页一个观点、层级更清晰，且只在有助于演讲节奏时使用由演讲者控制的逐步显示。

/slidewright 为季度工程复盘创建一套可复用的 React 演示文稿，然后准备一份在演讲后分享的 PDF 版本。
```

## 为什么不只用普通聊天机器人？

普通聊天机器人可以生成幻灯片文案，却容易把结果当作阅读文档或小型网页。SlideWright 从现场演讲的条件出发：观众在远处观看，一位演讲者控制整套演示，细节应由演讲者而非密集的屏幕文字传达。它保持适合投影的字号，把讲者备注与观众看到的视觉内容分开，提供现场导航，并为演示文稿选择合适的实现方式。

## 适合谁，以及何时使用

SlideWright 适用于会场演讲、会议分享、工作坊、课堂、演示、项目路演和内部汇报，只要内容将被投影或屏幕共享。它适合演讲者、教师、顾问、创始人和开发者；不适合阅读文档、仪表盘或需要观众操作的网站。

## 演示文稿如何成形

1. 说明演讲的目标，以及希望观众记住的一个核心信息。
2. 围绕观众和现场环境，塑造简洁的叙事和视觉方向。
3. 每页围绕一个观点，使用适合会场阅读的大字号，并在有助于理解时使用视觉素材。
4. 只加入由演讲者控制的变化：导航、逐步显示，或服务于叙事的对比。
5. 按目标屏幕检查演示文稿，准备独立的讲者备注；需要分享版本时请求导出 PDF。

详细的投影规则、布局模式和导出行为位于 [`references/`](./references/)，因此本页保持聚焦于你能获得的结果。

## 选择实现方式

| 方式 | 适用场景 | 心智模型 |
| --- | --- | --- |
| **单个 HTML 文件** | 需要短小、快速、便于携带的演示文稿，或不想要构建步骤。 | 一个可直接在浏览器中打开的自包含演示文稿；适合聚焦的演讲，但当内容丰富且超过约 15–20 页时会更难维护。 |
| **Vite + React** | 需要很多页面、可复用组件、更丰富动画、由状态驱动的演讲者交互，或需要长期维护。 | 一个以按顺序排列的组件作为页面的演示项目；需要 Node.js 和包管理器。 |

两种方式带给观众的体验相同：全屏演示、可见的演讲者导航和页码。应按演示文稿的复杂度和使用周期选择，而不是按视觉质量选择。

## 交互：为演讲者，而非观众

演讲者可通过键盘或底部导航前进、后退和跳转页面。逐步显示、标签、对比、计时器或动画，只有在改变演讲者正在讲解的内容时才合适。表单、登录、提交、收集答案或保存观众数据不属于这类演示文稿。

## 你需要提供什么

带来已有材料即可：演讲目标、观众、时长、核心信息、来源资料、要求页数、场地或屏幕限制，以及品牌色、标志、图片或语气指导。请说明你想要快速的 HTML 演示文稿还是易维护的 React 项目；如果不确定，只需描述演示文稿，技能可以帮助选择。

## 你将获得什么

- 可运行的 HTML 或 React 演示网站
- 一致的视觉方向，以及投影级布局和字号
- 演讲者导航、页码，以及有明确目的的逐步显示或动画
- 单独的 Markdown 讲者备注文件
- 视觉检查指导，以及按需提供的、便于分享的忠实 PDF 导出

## 有用的搭配技能

- 当演讲角度、核心信息或示例仍未确定时，先使用 [Brainstorm Coach](../brainstorm-coach/README.zh.md)；它会帮助你探索并收敛可能性，再构建叙事。
- 当路演、战略或证据密集的演示需要压力测试其论证时，使用 [Critical Thinking](../critical-thinking/README.zh.md)；它能在观众提出之前发现证据不足的主张和最强反对意见。

## 限制

SlideWright 支持一位演讲者操作一块屏幕、观众观看的场景。它不构建面向观众的应用，不收集或保存回应，也不代替演讲者对主张或来源材料的判断。PDF 是便于分享的演示捕获，而不是可访问来源文档的替代品；请在实际活动环境中排练并检查最终版本。
