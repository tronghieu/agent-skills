# Brainstorm Coach

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

在不把思考交给 AI 的前提下，把尚不明确的问题转化为原创、可追溯的方案和可行的下一步。

## 安装

```bash
npx skills add tronghieu/agent-skills --skill brainstorm-coach
```

## 立即尝试

```text
/brainstorm-coach 帮我为一款重视隐私的金融应用取名。
/brainstorm-coach 探索社区工具借用库的发布创意；我们只有 200 美元和一个周末。
/brainstorm-coach Party mode：从不同角度审视我的转行想法，再对候选方案做红队评估。
```

## 为什么不只用普通聊天机器人提示词？

普通提示词常常在你来得及思考之前，就给出一份看似完整的清单。Brainstorm Coach 把过程当作协作：你先贡献想法，原话会被保留，AI 再以清晰标签补充少量延展或新方向。它把判断留到探索之后，为问题选择合适的方法，再帮助你归类、检验和选择方向。结果不只是更多点子，还是一份能说明点子从何而来、为什么值得保留的记录。

## 适合谁

当你在探索名称、功能、活动、事件、产品方向、创作项目或职业选择时，可以使用它。它适合创始人、产品和营销团队、设计师、写作者，以及任何需要新可能性、但不想沦为 AI 点子清单旁观者的人。

它尤其适合主题仍然开放、想法已经陈旧，或充满尚未成形直觉的场景。你可以带来一份具体 brief，也可以只带一个模糊问题；两者都是有效起点。

## 方法：选择适合问题的模式

教练可以推荐方法、展示一份简短的相关菜单、随机选择，或带领你从宽泛探索逐步收敛。只要某种方法仍能产出，它就会继续使用，而不是机械地逐项走完清单。

可用方法包括：

- **打开空间：** What-if 情境、类比思维、逆向思考和第一性原理会挑战习以为常的框架。
- **加入结构：** SCAMPER 用于改进具体产品或流程；六顶思考帽分开不同视角；思维导图整理相互关联的线索。
- **建立动能或广度：** Yes-and、轮流脑写和随机刺激适合能量下降，或一个点子正在锚定整个讨论时。
- **深入或锐化：** 探索式五个为什么寻找底层需求；形态分析组合不同维度；挑衅、假设反转、角色扮演、资源约束、隐喻和问题风暴用来松动卡住的框架。

完整会话可以使用两到四种方法，但一种好方法胜过对许多方法的浅尝辄止。

## 对话如何进行

1. **界定会话。** 说明主题、硬约束，以及你想宽泛探索还是集中回答。
2. **共同生成。** 每轮只有一个问题。你先回答；你的想法会原样记录为 `(user)`。随后 AI 给出少量延展或新方向，并标记为 `(AI)`。
3. **检查能量。** 几轮之后，决定继续、切换方法还是收敛。在发散阶段，不会给想法排序或否决。
4. **有意识地收敛。** 把相关想法归组，保留来源标签；任何排序都给出理由，供你质疑。
5. **落实下一步。** 在教练给出自己的选择前，先由你选出前三项；每项都会有最小的下一步行动，以及判断是否值得继续的学习方式。

## Party mode：视角，不是表演

Party mode 是可选的：你可以直接提出、在讨论开始重复时使用，或要求对候选清单进行红队评估。它会为当前主题选择三到四个**角色视角**，例如某个具体客户、必须交付这个想法的执行者、局外人和挑衅者。

这些是简短的工作视角，不是带姓名、背景故事的角色，也不会模拟一个小组的对话。你仍然先给出想法。教练会把各视角汇总成一份紧凑摘要，用 `(AI:operator)` 等形式标记，并控制总量。在探索时，怀疑视角会把反对意见转换成生成性问题；在收敛时，红队会给出最强异议、能证伪该想法的事实，以及最低成本的降风险方式。

## 你带来什么，得到什么

带来主题、期望结果、约束和已有想法即可；粗略笔记也完全可以。你还可以选择是否保留会话文档。

你会得到可追溯的想法记录、主题簇、四个实用分类（可立即开展的机会、未来创新、登月计划和洞察）、你的前三项、后续步骤，以及用于保存有价值岔路的停车场。若保留文档，它会记录主题、约束、模式、使用的方法、想法、分类和后续行动。

## 与这些 skill 配合使用

- 当某件事正在失败但原因未知时，先用 [Problem Solver](../problem-solver/README.zh.md)；先诊断，再构思修复方案。
- 当关键未知是人们真正需要什么，并且需要以用户为中心的研究时，使用 [Design Thinking](../design-thinking/README.zh.md)。
- 当一个有前景的想法需要验证需求、竞争对手或市场规模时，使用 [Market Researcher](../market-researcher/README.zh.md)。
- 当选择已经成为公司层面的战略押注时，使用 [Strategy Board](../strategy-board/README.zh.md)。
- 当你已经把想法写成提案，并想压力测试其中的推理时，使用 [Critical Thinking](../critical-thinking/README.zh.md)。

## 限制

Brainstorm Coach 用于生成和组织可能性；它不会证明市场需求、开展用户研究、诊断根因，也不会替你做最终决定。它也不会假装每个狂野点子都同样成熟而把它们全部保留——评估发生在发散之后，并应有明确的理由和可执行的检验支撑。
