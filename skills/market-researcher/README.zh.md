# Market Researcher

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

以新近、可引用的案头研究支持市场决策，而不是接受无法核验的聊天机器人答案。

## 安装

```bash
npx skills add tronghieu/agent-skills --skill market-researcher
```

立即尝试：

```text
/market-researcher 面向德国独居者的订阅式餐包服务值得投入吗？请做快速扫描。
```

```text
/market-researcher 估算东南亚 B2B 费用管理软件的 TAM、SAM 和第三年 SOM。
```

```text
/market-researcher 加拿大中端会计 SaaS 的直接竞争者、替代方案和“维持现状”分别是什么？
```

```text
/market-researcher 深度调研：哪些监管、支付行为和趋势可能成就或扼杀一家越南电动车充电企业？
```

不同于普通聊天机器人的回答，每项事实性论断都关联到已登记的来源，估算会列明输入和公式，未解决的冲突或假设也会保留并清楚说明。

## 适合谁

当创始人、产品或增长团队、战略人员、顾问、商务拓展负责人或分析师需要证据来支持市场决策时，请使用此 Skill。典型决策包括是否构建、发布、进入、定价、定位，或是否值得继续研究。

它可聚焦一个或多个领域：

- 市场定义、TAM/SAM/SOM 与增长区间；
- 直接、间接、替代型和“维持现状”竞争者；
- 来自公开证据的需求与付费意愿信号；或
- 与决策相关的趋势、技术和监管。

## 研究如何保持严谨

首先，代理会确认决策、目标客户、地域和约束。随后，它研究最新网络资料和您提供的材料，登记每个来源的日期和可信度等级，并区分有来源的事实与假设。

市场规模测算采用明确的市场定义和可核验方法，例如购买单位数 × 价格。快速扫描使用一种方法加合理性检查，并给出较宽的区间；深度调研至少使用两种相互独立的方法。出现重大差异时，会解释原因——例如年份、定义、货币、收入指标或 GMV 不同——而非悄悄取平均值。

竞争分析会绘制买方实际可选方案的地图，包括不采取行动。需求分析从公开评价、社区、招聘信息和价格中挖掘信号，区分高频抱怨与用户正在为替代办法付费的证据。宏观与趋势分析只关注可能改变这一机会的少数因素，并说明每项因素对决策的影响。

交付前，怀疑者复核会检查最影响决策的论断、计算、日期和来源集中度。仍未解决的不确定性会成为明确的注意事项，而不会被掩盖。

## 你将如何开展

先说明你要做的决策。如已知，请提供产品或服务、买方、地域、时间范围、约束，以及什么证据会改变你的判断。代理默认执行 Quick Scan，并会在开始前确认研究框架。

| 模式 | 最适合的问题 | 范围 |
| --- | --- | --- |
| **Quick Scan**（默认） | “这值得进一步了解吗？” | 单次会话的 go/no-go 简报：一种规模测算方法及检查、5–10 个竞争者、主要需求信号，以及 2–3 个利好或致命因素。 |
| **Deep Dive** | “我们究竟要面对什么？” | 可跨会话续接的报告，只涵盖你选择的模块：规模、竞争者、需求和/或宏观环境。 |

你会获得带明确置信度的建议、驱动建议的事实、最大的注意事项，以及用于一手研究的开放问题。支撑材料包括来源登记表、可追溯的发现、计算输入与假设，以及报告。

在需求模块中，任何 persona 都会明确标为**待验证的假设**，绝不声称是客户事实。每个 persona 都关联到现有证据或标记为假设，并包含验证方法。

在代理可委派工作时，研究模块可并行执行，并使用各自的来源编号区间；否则会顺序执行。无论采用哪种方式，最终综合与核验都遵循同一套引用规则。

## 与其他 Skill 搭配

- 完成这项研究后，如需通过访谈、测试或原型来验证公开证据无法证明的需求假设和付费意愿，请使用 [Design Thinking](../design-thinking/README.zh.md)。
- 如需将这些市场证据与公司能力、权衡取舍和战略选项一并评估，请使用 [Strategy Board](../strategy-board/README.zh.md)。
- 如建议关乎重大决策，且希望严格审视其假设、推理和证据边界，请使用 [Critical Thinking](../critical-thinking/README.zh.md)。

## 限制

这是案头研究：它依赖可访问的网络来源和您提供的文件，不能替代客户访谈、问卷、行为观察，也不能替代财务或法律建议。公开信号可以提示需求和付费意愿，却不能证明某个具体客户会购买什么。若无法开展最新网络研究，此 Skill 应明确说明，而不是把记忆当作证据。
