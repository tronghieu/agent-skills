# CV Scorer

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

使用透明的 100 分评分标准，将一份或多份简历与职位描述（JD）进行比较——它只为人工审核提供决策支持，绝不替代招聘决策者。

## 安装

```bash
npx skills add tronghieu/agent-skills --skill cv-scorer
```

## 立即尝试

```text
/cv-scorer 按照附上的高级后端工程师 JD 为这份简历评分。

/cv-scorer 将这五份简历与这份产品经理 JD 比较，然后排序。

/cv-scorer 按 JD 审核这份数据分析师简历。列出缺失的必备条件和需要核实的事实。

/cv-scorer 为这个岗位评估这些营销候选人；对每份简历使用同一评分标准。
```

与普通聊天机器人的回答不同，CV Scorer 会显示标准、权重、基于证据的评语和建议标签，让审核者能够检查并质疑结果。

## 适合谁

招聘人员、招聘经理和小型招聘团队可以用它进行结构化初审、一致的批量比较，或准备针对缺失和矛盾信息的问题。它不能替代面试、背调或组织自身的招聘流程。

## 评分方式

该技能先从 JD 中提取必备条件、加分项、经验、教育背景和特殊要求，再将这些要求与每份简历中陈述的事实比较；不应以假设填补空白。每项标准按 1–10 分评分，再加权为 100 分总分。

| 标准 | 权重 | 最高分 |
| --- | ---: | ---: |
| JD 匹配度 | ×3 | 30 |
| 工作经验 | ×2.5 | 25 |
| 项目与影响 | ×1.5 | 15 |
| 教育背景 | ×1.5 | 15 |
| 简历质量 | ×1.5 | 15 |

详细档位覆盖 JD 满足程度、经验的相关性和发展、可信的项目指标、教育或资质，以及简历的结构和一致性。需要准确档位或扣分规则时，请阅读完整的[评分标准](./references/scoring-rubric.md)。

默认标签为 **Recommend**（70 分及以上）、**Maybe**（50–69 分）和 **Pass**（低于 50 分）。它们是供人工审核的提示，而不是自动邀约、淘汰或录用决定。

## 输入与结果

请提供完整 JD 和一份或多份文本、Markdown 或 PDF 格式的简历。回复遵循[输出格式](./references/output-format.md)：包含 JSON 评分明细、每项标准的评语、摘要、亮点和可能的风险标记。对多份简历，技能会先独立评分，再按从高到低返回批量排名。回复会匹配你的语言。

应将风险标记、信息缺失或表面矛盾视为待核实的问题，而不是对不诚信的认定。请复查每个分数背后的简历事实，尤其是接近阈值的候选人。

## 配套技能

- 当你需要审查招聘备忘录、政策或建议中的推理时，使用 [Critical Thinking](../critical-thinking/README.zh.md)；它会区分主张、证据、假设和漏洞，并把发现锚定到源文本。
- 对很长的招聘政策、作品集或支持材料（约 50 页以上），使用 [Deep Reader](../deep-reader/README.zh.md)；其多轮阅读笔记能让大型文档在用于审核前保持可追溯。

## 限制与负责任使用

- 一致地使用同一评分标准 **不** 表示分数客观或无偏见；简历也无法证明未来工作表现。
- 不得推断或评估受保护或敏感属性，例如年龄、性别、族裔、残障、宗教，或其他与工作无关的个人因素。
- 不得仅凭生成的分数或排名淘汰候选人。具备权限的人员必须审核证据并作出决定。
- 简历是自述且不完整的记录；应通过适当、合法的招聘步骤核实重要主张。
- 请遵守适用的劳动法、隐私义务和组织政策，包括任何留档或额外审核要求。
