# Deep Reader

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

用一套可追溯的方法阅读长篇书籍、论文、学位论文和教材，而不是只让聊天机器人做一次性摘要。

## 快速安装

```bash
npx skills add tronghieu/agent-skills --skill deep-reader
```

## 快速示例

```text
/deep-reader 研究这本 320 页的公共政策著作，帮助我准备文献综述。请追踪作者的因果论证、证据和未解决的假设。
```

```text
/deep-reader 请在周五前概览这本管理书。重点判断哪些建议适用于一家 30 人的软件公司，以及哪些地方证据薄弱。
```

```text
/deep-reader 对这三篇检索增强生成论文做主题阅读。重建它们的方法，分开结果与解释，并指出术语差异掩盖了哪些分歧。
```

## 适合谁

Deep Reader 适合处理约 50 页以上资料的研究者、研究生、分析师、教师和深度阅读者。当你需要理解论证、保留证据、比较资料，或在后续会话中继续追问时，它尤其有用。

对于能轻松放进一次对话的短文档，直接阅读通常更快。

## 为什么不只用普通聊天提示？

面对“总结这本 500 页的书”这样的请求，聊天机器人可能过早压缩内容、遗忘埋在文档中部的信息，或给出流畅却难以回查来源的答案。Deep Reader 改变了工作方法：

- 先确定你想从文本中获得什么，再决定哪些部分值得精读。
- 分轮阅读，而不是把整份文档当成一个超大提示。
- 用带页码锚点的笔记作为跨章节、跨会话的持久外部记忆。
- 区分作者的主张、论证、证据和读者自己的判断。
- 在给出综合结论前，检查重要引文和承重性主张。

它比快速摘要慢，但更可复用、可检查，也更适合严肃学习。

## 阅读方法

Deep Reader 结合了三套成熟方法：

1. **检视阅读——Adler：** 先绘制整部作品的地图，识别核心问题、整体统一性、结构、体裁，以及与你的目的最相关的章节。
2. **分析阅读——Adler：** 精读每个重要论证单元，跟踪关键术语、主要命题、前提、结论、证据、张力和开放问题。
3. **复述——SQ3R 的 Recite：** 写完笔记后，凭记忆复述章节，再回到原文核对，以便趁内容尚新鲜时发现误解。
4. **综合——Adler 的四个问题：** 作品整体讲什么；具体如何展开；在多大程度上真实或充分；以及它对你的实际目的意味着什么。
5. **主题阅读——Adler：** 当问题横跨多部作品时，先分别分析，再比较共识、冲突和术语，不让任何一位作者垄断整个议题的定义。

只有在公平复述作者立场后才进行批判判断。最终评价会区分“错误”“不完整”和“无法验证”，而不会把没有依据的异议包装成批评。

### 论文、学位论文和综述

学术文本采用 Keshav 的三遍阅读节奏：

- **第一遍：** 阅读标题、摘要、引言、各级标题、结论和参考文献，掌握大意。
- **第二遍：** 仔细阅读，记录关键证据，并标出仍需处理的证明、推导或参考资料。
- **第三遍：** 独立重建论文的论证或方法，再与原文比较。这个高成本步骤只用于与你的阅读目的真正相关的部分。

对于实证论文，技能会分开记录方法、结果和作者解释，避免把可靠结果与过度延伸的结论混为一谈。

## 选择深度

- **Overview：** 快速检视地图，加上针对最相关两到四个部分的目的导向摘要。适合建立方向、筛选资料，或判断一本书是否值得深入研究。
- **Study：** 完整流程——按章节或论证单元生成分析笔记、执行 Recite 检查、追踪跨章节术语、综合、绘制概念图并验证。适合研究、教学、评论写作或重要决策。

如果不确定，请说明目的和截止时间；技能会提出一种模式供你确认。

## 使用过程

1. 你提供资料，并说明希望学习、决策、教学或产出什么。
2. 技能先绘制作品地图，再提出精读计划。
3. 在 Study 模式下，技能按连贯的论证单元阅读，并持续保存带页码链接的笔记。
4. 方法会随体裁调整：哲学关注论证，历史关注史料与视角，科学关注证明或实验，文学关注人物与主题，教材则用练习检验理解。
5. 技能从经过检查的笔记进行综合，而不是依赖一个超大上下文中的模糊记忆。
6. 后续会话中再次提问时，技能会先搜索已有笔记，仅在缺少细节时才返回原文。

对于非常长的作品，技能可能把不同章节组放进隔离的阅读上下文或交给不同 agent。一个主读者仍统一负责作品地图、共享术语和最终综合，因此你得到的是连贯解释，而不是互不相连的小摘要。

## 你需要提供

- PDF、EPUB、DOCX、纯文本或 Markdown 源文件
- 阅读目的或需要支持的决策
- 关心的问题或主题
- 期望的深度、截止时间和输出语言
- 如需主题阅读，要比较的其他作品

## 你将获得

- **Overview：** 核心问题、整体统一性、结构和高价值部分的作品地图，以及围绕阅读目的的摘要。
- **Study 还会提供：** 带页码锚点的章节或部分笔记，涵盖主张、证据、术语和开放问题；跨章节的概念与术语图；针对阅读目的、回答 Adler 四个问题的综合报告；经过核对的引文，以及关键转述主张的验证记录；还有可复用笔记，用于后续追问而无需重读全部原文。

## 可与 Deep Reader 搭配的技能

以下是可选的后续组合，并非必需：

- 当你想专门审计原文推理，或审计基于综合报告做出的决策时，使用 [Critical Thinking](../critical-thinking/README.zh.md)。
- 当你想把笔记转化为引导式学习对话、口试练习或主动回忆时，使用 [Socratic Questor](../socratic-questor/README.zh.md)。
- 当资料包含需要重新分析的数据集或定量主张，而不仅是文本评价时，使用 [Data Scientist](../data-scientist/README.zh.md)。

## 局限

EPUB、DOCX、纯文本和 Markdown 的页码锚点是生成的坐标，不是印刷页码。扫描件、复杂排版、公式和表格也可能影响文本提取质量。用于学术、法律、医疗或正式出版的重要引文，仍应与原始版本核对。

Deep Reader 帮助你理解和评价资料；它不会让来源自动变得正确，不能替代领域专家，也不能在缺少数据时独立复现实验。
