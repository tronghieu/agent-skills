# System Prompt Creator

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

将产品或工作流说明转化为清晰、适配模型且可实际验证的系统提示词。

## 安装

```bash
npx skills add tronghieu/agent-skills --skill system-prompt-creator
```

## 从真实任务开始

```text
/system-prompt-creator 为内部 Python 代码审查助手创建系统提示词。它应简要说明发现的问题，且绝不能泄露机密。

/system-prompt-creator 将这份发票提取说明改写成输出 JSON 的提示词。保留每个原始值，标记不确定之处，并给出三个测试用例。

/system-prompt-creator 为订单咨询和退款设计客服 Agent。它可以查询订单，但修改订单前必须征得确认。

/system-prompt-creator 改进这份用于研究助手的 GPT 提示词。目标为 GPT-5，应引用提供的来源并区分事实与推断：[粘贴提示词]
```

普通聊天机器人提示词通常只引导一次对话；系统提示词则定义可重复评估的行为：范围、决策方式、工具使用、输出契约与边界，并能在多种输入上检验。

## 适合谁，以及何时使用

如果你在构建 AI 产品、自动化工作流，或需要可靠的自定义指令，请使用此 skill。它适用于助手和聊天机器人、代码助手、内容工具、数据提取、研究工作流、使用工具的 Agent，以及需要在不同模型系列间迁移的提示词。当结果不一致、任务需要结构化输出，或系统需要明确安全、升级与失败处理方式时尤其适合。

## 如何协作

用日常语言描述工作即可。此 skill 会访谈目标模型、用户、输入、输出、语气、工具、约束、示例以及可能出现的相邻请求。信息不足时，它可以提出合理默认值供你确认。

接着，它会评估提示词复杂度，分离角色、上下文、指令、输出契约、示例、工具规则与护栏，并仅在适合时采用 XML 或 Markdown。草案强调明确意图、相容规则、正向指引，以及覆盖常规、边界和超出范围情形的示例。最后，它提供测试提示词，并根据观察到的失败进行修订。

对于 Agent 提示词，设计可以加入具名操作 playbook、安全/谨慎/必须确认的行动分级、工具规则、状态管理和最终验证循环。对于多 Agent 设计，请明确职责、交接和适合并行委派的条件；不要假定这些会从笼统的人设中自然产生。

## 需要提供什么，会得到什么

尽可能提供以下信息：

- 目标提供商、模型和版本；使用场景；受众；以及所需人设。
- 输入类型、必需输出格式、语气、工具、权限、硬约束、有用示例或已知失败情况。
- 对高影响工作流，提供代表性数据，以及必须由人工确认的决策。

你将获得可直接复制的系统提示词草案、关键假设与架构说明、在有依据时给出的模型相关调整，以及 3–5 个带预期行为的验证提示词。提取类设计可以保留原始来源值并表达不确定性；Agent 设计可以定义 playbook 和行动边界。

## 针对实际部署的模型进行验证

请将提供商特定建议、API 参数和模型行为视为随版本变化的指导，而不是永久事实。确认模型名称/版本和提供商当前官方文档后，再以准确的部署设置运行随附测试，以及你自己的代表性或对抗性案例。更换模型、上下文窗口、工具、API 参数或产品政策后，应重新测试。详见[模型说明](./references/model-specific.md)、[原则](./references/principles.md)和[模板](./references/templates.md)。

## 配套 skills

- 当提示词输出需要成为面向读者的长期教程、操作指南、参考或解释文档时，使用 [Diataxis Writer](../diataxis-writer/README.zh.md)。
- 当高影响提示词包含需要独立审查推理和证据的政策、主张或决策时，使用 [Critical Thinking](../critical-thinking/README.zh.md)。
- 当评估提示词变更需要分析测试集、指标或错误模式时，使用 [Data Scientist](../data-scientist/README.zh.md)。
- 当真正的不确定性在于用户需求、行为或采纳情况而非措辞时，先使用 [Design Thinking](../design-thinking/README.zh.md)。

## 限制

精心设计的提示词可以提高一致性，但不能保证正确性、安全性、合规性、工具调用成功，或不同模型和版本间完全一致的行为。提示词不能替代授权控制、检索质量、产品政策、人工审核或生产环境评估。
