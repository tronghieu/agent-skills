# Strategy Board

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

把一项重要商业问题转化为有来源、经压力测试、可供高管真正作出选择的建议。

## 安装

```bash
npx skills add tronghieu/agent-skills --skill strategy-board
```

## 从一个决策开始

用自然语言输入 `/strategy-board`。例如：

```text
/strategy-board 我们明年是否应进入印度尼西亚？若进入，应从哪个细分市场开始？
/strategy-board 比较为我们的仓库管理系统自建、采购与合作三种方案。
/strategy-board 在提交董事会审批前，压力测试拟议收购。
/strategy-board 我们需要一份年度计划，在产品组合之间重新分配资源。
```

## 为什么不用普通聊天机器人？

普通聊天可能一次就给出听起来合理的答案。Strategy Board 的设计目标是让决策更经得起审视：

- 先建立事实基础，再得出结论；数字必须有来源，或明确标为假设。
- 至少比较三条真实且实质不同的路径，而不是一个偏好答案加两个陪衬。
- 分开审视市场、创新、财务、执行、不确定性和风险，避免一处的乐观掩盖另一处的弱点。
- 在建议形成前红队检验已选方向，记录仍然存在的风险，并明确取舍——包括不做什么。

## 适合谁

适合对重大选择负责的创始人、高管、业务单元负责人、战略负责人和顾问：市场进入、重大投资、自建或采购、定价、产品组合优先级、转型、竞争应对、扭亏、并购或年度规划。聚焦的单项分析，例如预演失败或机会规模测算，也可以只调用相关专家，无需完整项目。

## 项目如何进行

管理合伙人会先确认真正的决策、范围、成功标准、约束、风险偏好和战略环境。完整项目随后经过清晰的复核节点：

1. **简报：** 界定决策，并与高管确认问题。
2. **事实基础：** 汇集公开证据和你提供的内部事实；将缺口登记为具名假设。
3. **针对性分析：** 只采用该问题需要的战略视角。
4. **选项：** 用相同标准比较三条可辩护的路径；由高管选择方向。
5. **压力测试：** 在建议前检验失败路径、情景、证据和执行依赖。
6. **建议：** 交付先给答案、适合董事会审阅的论证，包含被否决的选项、接受的风险和明确牺牲；高管批准或修订。
7. **路线图：** 把获批选择转化为负责人、90 天行动、产出指标、资源再分配、信号和复核触发条件。

委员会会在简报、选项和建议三个关口暂停。你可以细化、深入、质疑分析或继续；缺失的内部信息会保留为假设，而不会变成编造的确定性。

## 你需要提供

请提供决策和期限、期望结果、范围、硬约束、风险承受度、利益相关者、相关内部经济数据与组织能力、过往尝试，以及哪些证据会改变你的判断。委员会可以研究公开来源，但除非你提供，否则无法得知内部现实。

## 你将获得

- 已确认的决策简报，以及证据/假设登记表
- 相关专家分析及其对决策的影响
- 按相同标准比较的战略选项
- 包含预警信号和缓解措施的预演失败或情景压力测试
- 可供董事会使用的建议、决策记录，以及——获批后——执行路线图

对于单项分析，主要交付物是一份自成一体的备忘录；支持材料作为附录提供，而不是必读内容。

## 委员会与 Boardroom 讨论

**Drucker** 管理项目并质询问题框定。专家分别承担不同职责：**Porter**（市场与竞争）、**Christensen**（创新与客户任务）、**Graham**（价值与下行情景经济性）、**Grove**（能力与执行）、**Wack**（情景与不确定性）、**Taleb**（红队风险）和 **Minto**（先给答案的综合表达）。

对于确有分歧的选择，你可以召开 Boardroom 会议。三到四位相关成员会先给出独立立场——必要时作为并行工作流——然后才看到彼此观点。你将看到共识、真正的分歧、简短交叉质询和记录在案的异议；这一顺序可减少群体思维，并暴露真正需要你判断的假设或取舍。委员会负责建议和记录；坐在主席位、作出最终决定的仍是你。

## 互补技能

- **需要大量外部证据？** 可先使用或同时使用 [Market Researcher](../market-researcher/README.zh.md)，获取带引用的市场规模测算、竞争对手梳理、需求信号和宏观研究；其有来源的发现可纳入事实基础。
- **需要现场呈现已批准的论证？** 建议完成建议后使用 [SlideWright](../slidewright/README.zh.md)，制作由演讲者控制的网页幻灯片。Strategy Board 提供论证与有来源的数字；SlideWright 将它们转化为演示视觉材料。

## 限制

Strategy Board 只提供建议：不会代你决策、批准投资、替代高管判断或编造事实。公开证据不能验证内部执行能力，也不能证明某个客户一定会购买。重要决策仍需适当的财务、法律、运营和领域审查。该方法会明确不确定性、异议和剩余风险，但不能消除它们。
