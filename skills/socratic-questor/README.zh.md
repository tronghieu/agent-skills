# Socratic Questor

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

与 Gadfly 一起把想法说出来：这位苏格拉底式伙伴用问题而非讲授，帮助你自行发现并检验理解。

## 安装

```bash
npx skills add tronghieu/agent-skills --skill socratic-questor
```

## 开始对话

```text
/socratic-questor 通过提问帮助我理解机会成本。
/socratic-questor 就这篇文章的论证考考我：[粘贴文本]。
/socratic-questor 我认为远程工作能提高生产力。请质疑我的推理。
/socratic-questor 一直问我，直到我能用自己的话解释光合作用。
```

## 为什么不用普通聊天机器人？

普通聊天机器人往往给你一份可直接消费的完整答案。Gadfly 会先让你当前的理解模型变得清晰，再检验其中的假设、证据、替代视角和后果。你练习的是推理，而不只是记住另一段解释。

## 适合谁，何时使用

如果你是学生、自学者、教师、导师或领域专家，并希望通过对话审视自己的理解，就可以使用 Socratic Questor。它尤其适合用来：

- 通过自行表述来学习一个概念；
- 检查自己能否用自己的话解释主题或源文本；
- 在依据某项主张作决定前先挑战它；或
- 探索假设、证据、竞争性观点和影响。

## 提问方法

Gadfly 将 Paul & Elder 的苏格拉底式提问框架用作灵活的漏斗：

```text
澄清 → 假设 → 证据 → 视角 → 影响 → 元反思
```

对话总是从澄清开始，让 Gadfly 先听到你的问题框架。之后，它会跟随你的回答：含糊的回答可能需要再次澄清；没有支撑的主张会引向证据；片面的论证会引入其他视角。这个顺序是指南针，而不是固定脚本。参阅完整的[提问框架](./references/questioning-framework.md)。

## 学习互动是什么样的

Gadfly 友善、好奇，并带一点挑衅性；这个人格名称来自苏格拉底所说的“雅典牛虻”。它会简短肯定一个有价值的观点，然后提出一到两个真诚的问题，给你思考和回答的空间。它会使用你所使用的语言。

对话会按每次回答的质量持续调整：

- **刚接触主题：** 放慢澄清节奏，使用更小或更具体的问题，并提供更多支架。
- **已有基础：** 温和地提出矛盾，更仔细地审视假设与证据。
- **基础扎实：** 更快转向反驳、影响，以及对自身推理的反思。

如果你卡住了，Gadfly 会缩小问题、换一种说法，或给出具体情境或类比。它仍不会直接给出答案；这保留了通过自主发现来学习的约定。

## 你带来什么；可以期待什么

| 你带来什么 | 可以期待什么 |
| --- | --- |
| 一个待探索的主题，例如概念、决策或主张 | 节奏合适的问题序列，每轮一到两个问题 |
| 或一篇希望理解的文本/文档 | 简短肯定，以及基于你的回答继续深入的追问 |
| 诚实的回答，即使尚不完整 | 根据你实际展现的推理调整的问题，而不是根据你自称的水平 |

## 配套 skills

- 当你需要在对话之后系统审查一段论证时，使用 [Critical Thinking](../critical-thinking/README.zh.md)；它能把已经浮现的主张与证据转化为有意识的评估。
- 当起始材料是一整本书或长篇论文时，使用 [Deep Reader](../deep-reader/README.zh.md)；它能在苏格拉底式讨论之前或期间提供系统化的阅读过程。
- 当你想把学到的内容写成清晰文档时，使用 [Diataxis Writer](../diataxis-writer/README.zh.md)；它会按读者需求区分学习、任务指导、参考和解释。

## 限制

Gadfly 通过提问教学，而非直接讲解。当你需要即时事实、完整示范解答或事实核查时，它并不适合。尤其在高风险情境中，应把对话中出现的主张视为进一步核实的起点。
