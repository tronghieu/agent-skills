# Fiction Studio

**语言：** [中文](./README.zh.md) | [English](./README.md) | [Tiếng Việt](./README.vi.md)

把散文小说的构想、草稿或系列项目发展为由作者主导、讲究写作技艺，并从前提到修订都保持连贯的作品。

## 快速安装

```bash
npx skills add tronghieu/agent-skills --skill fiction-studio
```

## 用一个请求开始

```text
/fiction-studio 我有一个哥特式悬疑小说前提。请检验它对读者的承诺，再帮我选择大纲路线。
```

```text
/fiction-studio 我的主角在第 1–3 章过于被动。请在不丢失现有情节的前提下，重建她的欲望、创伤与转折点。
```

```text
/fiction-studio 这是我写好的对峙场景。请进行一轮对话修改，让潜台词和人物声音更鲜明，再给我修订选项。
```

```text
/fiction-studio 我在奇幻小说的悲剧结局和希望结局之间犹豫。请召开 writers' room 来检验这个选择。
```

## 为什么不用普通聊天机器人提示词？

普通提示词能生成流畅的文字，却常把规划、写作、批评和修订混在一段难以追溯的回答里。Fiction Studio 将这些工作分成独立轮次，把已确认的决定保留为工作产物，并停下来让作者作选择。具名的写作视角让反馈更准确：结构问题不会被当成句子润色，读者反应也不会被误当成必须执行的指令。

## 适合谁、何时使用

适合创作长篇小说、中篇小说、短篇小说和散文体系列的新作者与有经验作者。可用于：

- 把前提变成尊重类型预期的故事计划；
- 诊断情节、人物、世界、场景、文笔或对话的问题；
- 根据现有大纲起草，或修订已有手稿；
- 获得聚焦的试读者反应，并决定哪些反馈值得采纳；
- 在长篇项目或多次写作会话中维持连续性。

短篇故事会采用精简流程，以免过度规划拖慢写作。系列作品则可先建立共享世界、类型承诺和系列主线，再让每一册走自己的流程。

## Studio 方法

Homer 协调项目，并在每一次聚焦处理之间把控制权还给作者。团队视角包括：Aristotle（情节与节奏）、Fyodor（人物心理）、Tolkien（世界与规则）、Scheherazade（场景与起草）、Oscar（对话）、Max（发展性与行文编辑）、Virginia（目标读者反应）、Borges（类型承诺与同类书）、Bloom（可选的文学批评）。

一部长篇新作通常经过：

1. 前提与类型承诺
2. 大纲——结构式大纲或 Snowflake 式扩展
3. 人物与世界
4. 场景清单与散文起草
5. 对话修改与发展性编辑
6. 试读、反馈分级与最终润色
7. 打包：推介材料与合并后的手稿

每一阶段由相应专长视角阅读前面的成果、产出下一份工作材料，并在项目推进前与你确认。质量关口会关注结构、类型预期、铺垫与回收、连续性和文笔；它们辅助判断，而不取代判断。

## 使用体验

你只需带来目前已有的材料。一个模糊想法可以从前提出发；已有大纲、场景或手稿则可直接进入所需轮次。你会得到少量真正有意义的选择——例如提高风险、改变场景价值转折、检验人物动机，或尝试更大胆的方案——而不是让 Studio 悄悄替你决定故事。你批准方向，并始终保有作者主导权。

## 输入、输出与工作产物

有用的输入包括前提或文本、类型与目标读者、基调、创作限制、参考作品，以及必须保持为 canon 的决定。

视范围而定，Studio 可建立或更新前提、大纲、人物档案、世界圣经、场景清单和手稿章节。长篇项目还可保留机器可读的 canon，用于姓名、事实、时间线、规则和铺垫；以及试读笔记、按优先级排列的修订计划、推介包。推介包可包括一句话简介、腰封文案、梗概、同类书、元数据和可选的投稿信。这些持久材料让下一次会话从已有成果继续，而非依赖模糊记忆。

## Writers' Room：多角色 party mode

常规流程在起草和编辑等生产工作中一次使用一个聚焦角色。Party mode 则不同：当探索需要有价值的分歧时，它会邀请三到四个相关视角共同讨论——最常见于塑造前提时，或遇到结局、类型转向、人物卡住等重大分叉时。

讨论会围绕一个问题展开，先收集不同看法，再让这些看法彼此检验，最后把选择交还给你。结束时，选定方向、仍可选择的方案和未解决的问题会被记录到项目中。它刻意不用于句子编辑、起草或日常连续性检查，因为此时单一的聚焦轮次更清楚。

## 可搭配的 Skill

- 当想法本身仍很开放、你希望在确定前提前先探索和排序各种可能性时，先使用 [Brainstorm Coach](../brainstorm-coach/README.zh.md)。
- 当小说取材于长篇资料——例如公版作品、历史来源或一组同类文学作品——并且你需要可追溯的笔记，再把理解转化为故事选择时，使用 [Deep Reader](../deep-reader/README.zh.md)。
- 当类型定位、读者信号或出版市场假设需要最新且带引文的案头研究时，使用 [Market Researcher](../market-researcher/README.zh.md)，再把结果带回以完善类型承诺和同类书。

## 限制

Studio 支持散文小说创作，并非完整的出版、法律、授权或专业敏感性审查服务。类型惯例和试读反应是视角，不是规则；作者决定保留、修改或拒绝什么。连续性记录和质量检查能发现许多风险，却不能保证文笔质量、文化准确性、市场成功，或重研究型小说中事实的准确性。
